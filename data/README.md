clear = 값을 기준으로 normal/potential/urgent 나눌 수 있는 biomarker / unclear = 값을 기준으로 normal/potential/urgent 나눌 수 없는 biomarker

| data | 설명 |
| --- | --- |
| [biomarker.csv](data/biomarker.csv) | clear한 biomarker |
| [health_instruction.csv](data/health_instruction.csv) | clear한 biomarker (컬럼에서 조건 부분 제거함 ) + unclear 한 biomarker |
| [raw biomarker.csv](data/raw_biomarker.csv) | 모든 column + clear한 biomarker + unclear 한 biomarker |
| [events.csv](data/events.csv) | 이벤트 더미데이터. 제작할 때 [나사 블로그](https://www.nasa.gov/blogs/spacestation/) 참고함 |
