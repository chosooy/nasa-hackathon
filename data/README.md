*clear = 값을 기준으로 normal/potential/urgent 나눌 수 있는 biomarker
*unclear = 값을 기준으로 normal/potential/urgent 나눌 수 없는 biomarker

clear biomarker.csv = clear한 biomarker

clear+unclear biomrkaer.csv = clear한 biomarker (컬럼에서 조건 부분 제거함 ) + unclear 한 biomarker

raw biomarker = 모든 column + clear한 biomarker + unclear 한 biomarker
